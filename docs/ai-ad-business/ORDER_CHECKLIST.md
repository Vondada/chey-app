# Order intake checklist — before creative work starts

Copy one block per client. Do not start the clock until **Payment** and **Required assets** are checked.

---

## Client

- [ ] Business name: _______________________
- [ ] Contact name + phone / IG: _______________________
- [ ] City / neighborhood: _______________________
- [ ] Package: [ ] $500 Tonight  [ ] $250 Mid  [ ] $150 Starter
- [ ] Need-by time (local): _______________________

## Payment

- [ ] Method: [ ] Cash App  [ ] Venmo  [ ] Stripe link  [ ] Other: _______
- [ ] Amount received: $_______
- [ ] Confirmation (screenshot / txn id): _______________________
- [ ] Rule: finals only after payment (or 50/50 if you already trust them)

## Required assets

- [ ] Logo file received (PNG preferred)
- [ ] Product / space photos (min 2, ideally 4–6)
- [ ] Offer text (exact wording + price + end date if any)
- [ ] CTA: [ ] Call  [ ] Text  [ ] DM  [ ] Book link  [ ] Visit in store
- [ ] Phone / URL / handle to print on creative: _______________________

## Brand preferences (optional but useful)

- [ ] Brand colors (hex or “match logo”)
- [ ] Fonts / vibe words (clean, bold, cozy, luxury, playful…)
- [ ] Words / claims to avoid
- [ ] Competitor style they like (describe — do not copy)

## Placement

- [ ] Instagram feed
- [ ] Instagram / FB story
- [ ] Facebook page
- [ ] Google Business profile
- [ ] Print flyer (note: design for digital first; print needs bleed)

## Deliverables checklist (owner)

### $500 Tonight Pack
- [ ] 4× 1080×1080
- [ ] 2× 1080×1920
- [ ] Captions A + B in captions.txt
- [ ] One revision window noted (24h, typos/price/phone only)

### $250 Mid
- [ ] 3× square + 1× story + 2 captions

### $150 Starter
- [ ] 2× square + 1 caption

## Handoff

- [ ] Zip / folder named `BusinessName_Pack_YYYY-MM-DD`
- [ ] Sent via: _______________________
- [ ] Asked for review + one intro
- [ ] Logged in your notes (amount, date, what sold)

## CHE Office (optional)

- [ ] Art Studio / media used for image drafts if Worker image gen is connected
